# Computer Use

Плагин для управления компьютером через скриншоты и клики. Требует установленный pyautogui.

## Возможности

- Скриншот всего экрана
- Клик по координатам

## Инструменты

### screen_capture

Делает скриншот всего экрана.

**Возвращаемое значение:**
- `success` (bool): Успешность операции
- `width` (int): Ширина скриншота
- `height` (int): Высота скриншота
- `format` (string): Формат изображения (PNG)

### screen_click

Клик по указанным координатам.

**Параметры:**
- `x` (int): Координата X (обязательно)
- `y` (int): Координата Y (обязательно)
- `button` (string): Кнопка мыши (left, right, middle)

**Возвращаемое значение:**
- `success` (bool): Успешность операции
- `x` (int): Координата X
- `y` (int): Координата Y
