# Mobile / Performance Doctor

Плагин для анализа производительности и совместимости с мобильными устройствами в Unreal Engine 5.7.

## Возможности

- Сканирование материалов на риски для мобильных устройств
- Поиск тяжёлых шейдеров
- Профилирование уровня (акторы, треугольники, огни)

## Инструменты

### check_mobile_compat

Сканирует материалы проекта на потенциальные проблемы совместимости с мобильными устройствами.

**Параметры:**
- `project_path` (string, опционально): Путь к проекту
- `strict_mode` (bool): Строгий режим проверки (по умолчанию false)

**Возвращаемое значение:**
- `materials_scanned` (int): Количество проверенных материалов
- `issues` (array): Список найденных проблем
  - `path`: Путь к материалу
  - `issue`: Описание проблемы
  - `severity`: Уровень серьёзности (low, medium, high)
- `risk_score` (float): Оценка риска (0-100)

### find_expensive_materials

Находит и ранжирует материалы по "тяжести" шейдеров.

**Параметры:**
- `project_path` (string, опционально): Путь к проекту
- `limit` (int): Максимальное количество результатов (по умолчанию 20)

**Возвращаемое значение:**
- `materials` (array): Список материалов с оценкой тяжести
  - `path`: Путь к материалу
  - `complexity_score`: Оценка сложности (0-100)
  - `issues`: Список проблем
- `count` (int): Количество найденных материалов

### profile_level

Профилирует открытый уровень в редакторе Unreal.

**Параметры:**
- `include_hidden` (bool): Включать скрытые акторы (по умолчанию false)

**Возвращаемое значение:**
- `actor_count` (int): Количество акторов
- `triangle_count` (int): Общее количество треугольников
- `dynamic_light_count` (int): Количество динамических огней
- `static_light_count` (int): Количество статических огней
- `memory_estimate_mb` (float): Оценка использования памяти
- `performance_rating` (string): Оценка производительности (good, fair, poor)
