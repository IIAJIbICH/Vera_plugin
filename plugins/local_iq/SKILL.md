# Local IQ

Плагин для сохранения и поиска рецептов (последовательностей шагов) в JSONL-хранилище.

## Возможности

- Сохранение рецептов с шагами выполнения
- Поиск рецептов по задаче/названию
- Категоризация рецептов

## Хранилище

Рецепты хранятся в файле `recipes.jsonl` в папке плагина в формате JSON Lines.

## Инструменты

### save_recipe

Сохраняет последовательность шагов (рецепт) для решения задачи.

**Параметры:**
- `task` (string): Описание задачи (обязательно)
- `steps` (array): Список шагов выполнения (обязательно)
- `category` (string, опционально): Категория рецепта
- `notes` (string, опционально): Дополнительные заметки

**Пример использования:**
```json
{
    "task": "Создание персонажа",
    "steps": [
        "Создать новый Blueprint Actor",
        "Добавить Static Mesh Component",
        "Настроить Collision",
        "Добавить Camera Component"
    ],
    "category": "blueprint"
}
```

**Возвращаемое значение:**
- `id` (string): Уникальный ID рецепта
- `task` (string): Описание задачи
- `steps_count` (int): Количество шагов

### find_recipe

Ищет рецепт по задаче или названию.

**Параметры:**
- `task_query` (string): Поисковый запрос по задаче (обязательно)
- `category` (string, опционально): Фильтр по категории
- `limit` (int): Максимум результатов (по умолчанию 5)

**Возвращаемое значение:**
- `results` (array): Найденные рецепты
  - `id`: ID рецепта
  - `task`: Описание задачи
  - `steps`: Шаги выполнения
  - `category`: Категория
- `count` (int): Количество результатов
