# Source Control (Git)

Плагин для работы с Git в проектах Unreal Engine 5.7.

## Возможности

- Просмотр статуса репозитория
- Получение diff изменений
- Просмотр истории коммитов
- Создание коммитов с явным указанием файлов

## Инструменты

### git_status

Получает статус Git репозитория проекта.

**Параметры:**
- `repo_path` (string, опционально): Путь к репозиторию (по умолчанию ищется от корня проекта)

**Возвращаемое значение:**
- `branch` (string): Текущая ветка
- `changed_files` (array): Изменённые файлы
- `staged_files` (array): Файлы в индексе
- `untracked_files` (array): Неотслеживаемые файлы
- `total_changes` (int): Общее количество изменений

### git_diff

Получает diff для указанных файлов.

**Параметры:**
- `paths` (array): Список путей к файлам (опционально, все файлы если не указано)
- `repo_path` (string, опционально): Путь к репозиторию

**Возвращаемое значение:**
- `stat` (string): Краткая статистика изменений
- `diff` (string): Полный diff

### git_log

Получает историю коммитов.

**Параметры:**
- `max_count` (int): Максимальное количество коммитов (по умолчанию 10)
- `repo_path` (string, опционально): Путь к репозиторию

**Возвращаемое значение:**
- `commits` (array): Список коммитов
  - `hash`: Hash коммита
  - `author_name`: Автор
  - `author_email`: Email автора
  - `date`: Дата коммита
  - `message`: Сообщение коммита
- `count` (int): Количество коммитов

### git_commit

Создаёт новый коммит с указанными файлами.

**Параметры:**
- `message` (string): Сообщение коммита
- `paths` (array): Список путей к файлам для коммита (обязательно)
- `repo_path` (string, опционально): Путь к репозиторию

**Пример использования:**
```json
{
    "message": "Добавлен новый уровень",
    "paths": ["Content/Levels/NewLevel.umap"]
}
```

**Возвращаемое значение:**
- `commit_hash` (string): Hash созданного коммита
- `message` (string): Сообщение коммита
- `files_count` (int): Количество файлов в коммите

**Важно:** Этот инструмент НЕ использует `git add all`. Только явно указанные файлы будут добавлены в коммит.
