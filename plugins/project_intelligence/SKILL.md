# Project Intelligence

Плагин для анализа проекта Unreal Engine без запуска редактора. Работает напрямую с файловой системой.

## Возможности

- Анализ файла .uproject
- Анализ подключенных плагинов
- Поиск активов (.uasset, .umap) по имени
- Статистика проекта

## Инструменты

### analyze_project

Анализирует проект Unreal Engine: читает .uproject файл, анализирует плагины и активы.

**Параметры:**
- `project_path` (string, опционально): Путь к проекту (по умолчанию используется текущий проект)
- `include_assets` (bool): Включить анализ активов (по умолчанию false)

**Возвращаемое значение:**
- `project_name` (string): Имя проекта
- `engine_version` (string): Версия движка
- `plugins` (array): Список плагинов
- `asset_count` (int): Количество активов (если include_assets=true)
- `map_count` (int): Количество карт

### find_asset

Ищет файлы активов (.uasset, .umap) по имени или части имени.

**Параметры:**
- `name` (string): Имя или часть имени для поиска (обязательно)
- `extensions` (array): Расширения для поиска (по умолчанию [".uasset", ".umap"])
- `project_path` (string, опционально): Путь к проекту

**Пример использования:**
```json
{
    "name": "PlayerCharacter",
    "extensions": [".uasset"]
}
```

**Возвращаемое значение:**
- `results` (array): Найденные файлы
  - `path`: Полный путь к файлу
  - `relative_path`: Относительный путь от Content
  - `size_bytes`: Размер файла в байтах
- `count` (int): Количество найденных файлов
