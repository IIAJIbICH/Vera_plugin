# Smart Refactor

## Инструменты

### rename_asset_safe
Переименовывает ассет с обновлением ссылок.

### find_duplicate_assets
Ищет дубликаты ассетов по хешу содержимого.

### analyze_blueprint_complexity
Анализирует сложность Blueprint (количество нод, связей).

### suggest_optimization
Даёт рекомендации по оптимизации проекта.
