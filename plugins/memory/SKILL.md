# Memory

Плагин для сохранения и поиска воспоминаний (фактов) в JSONL-хранилище.

## Возможности

- Сохранение фактов с метаданными
- Поиск по содержимому воспоминаний
- Список всех воспоминаний
- Удаление воспоминаний по ID

## Хранилище

Воспоминания хранятся в файле `memories.jsonl` в папке плагина в формате JSON Lines (каждая запись на отдельной строке).

## Инструменты

### remember

Сохраняет факт/воспоминание в хранилище.

**Параметры:**
- `content` (string): Содержание воспоминания (обязательно)
- `category` (string, опционально): Категория воспоминания
- `tags` (array, опционально): Теги для поиска

**Пример использования:**
```json
{
    "content": "Главный герой предпочитает синие цвета",
    "category": "character",
    "tags": ["hero", "preferences"]
}
```

**Возвращаемое значение:**
- `id` (string): Уникальный ID воспоминания
- `created_at` (string): Время создания
- `content` (string): Содержание

### recall

Ищет воспоминания по запросу.

**Параметры:**
- `query` (string): Поисковый запрос (обязательно)
- `category` (string, опционально): Фильтр по категории
- `limit` (int): Максимум результатов (по умолчанию 10)

**Возвращаемое значение:**
- `results` (array): Найденные воспоминания
- `count` (int): Количество результатов

### list_memories

Возвращает список всех воспоминаний.

**Параметры:**
- `category` (string, опционально): Фильтр по категории
- `limit` (int): Максимум результатов (по умолчанию 50)

**Возвращаемое значение:**
- `memories` (array): Список воспоминаний
- `total` (int): Общее количество

### forget

Удаляет воспоминание по ID.

**Параметры:**
- `memory_id` (string): ID воспоминания для удаления (обязательно)
- `confirm` (bool): Подтверждение удаления

**Возвращаемое значение:**
- `deleted` (bool): Факт удаления
- `memory_id` (string): ID удалённого воспоминания
