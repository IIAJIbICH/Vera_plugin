# Level Architect

## Инструменты

### auto_place_actors
Расставляет акторы по правилам.

### generate_landscape
Генерирует ландшафт с настройками.

### create_room_layout
Создаёт комнату с заданными размерами.

### populate_with_foliage
Заполняет уровень фолиажем.

### create_path
Создаёт сплайновый путь.

### clear_level
Очищает уровень с фильтрами.

### auto_terrain_paint
Автоматическая покраска ландшафта.

### create_navigation_bounds
Создаёт навигационные bounds.
